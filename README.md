# IdlePeek

**Простой и таймауты сна.** Сколько уже нет клавиатуры и мыши, и когда текущая схема должна погасить экран или усыпить ПК.

**Автор:** darkshade ([@vlx0](https://github.com/vlx0))

**365 дней open source** · **неделя 11 — «Фон»** · день 75.

Не KeepAwake: та программа сама запрещает сон. Не ClockPulse: там МГц и кнопки схем. Не SleepHold: там кто держит ПК будным. Здесь только чтение.

---

## Возможности

- простой по `GetLastInputInfo`
- имя активной схемы и питание от сети или батареи
- таймауты экрана, сна, гибернации; режим отсутствия — вкл/выкл
- если простой уже больше таймаута — карточка желтеет или краснеет
- схему не переключает и сон не держит
- только Win32, без pip

## Установка

```powershell
git clone https://github.com/vlx0/IdlePeek.git
cd IdlePeek
pythonw run_idlepeek.pyw
```

Или `start.bat`.

Нужен Windows 10+ и Python 3.10+. Внешних зависимостей нет.
